## ResNet-18 两个种子的预测一致率

两份 100 轮训练历史和[训练配置](resnet18/training_config.json)与[一致率记录](resnet18/agreement.json)配套。两个种子都在 10,000 张 CIFAR-10 测试图像上正确分类了 9,429 张，在全部 10,000 张测试图像中，两个模型有 9,497 张预测一致。一致率是两个模型给出相同预测的比例。

| 评估对象 | 一致的点数 / 总点数 | 一致率 |
| --- | ---: | ---: |
| CIFAR-10 测试图像 | 9,497 / 10,000 | 94.97% |
| 图 3 所展示的固定平面，500 × 500 网格 | 224,369 / 250,000 | 89.75% |
| 500 个测试三元组平面，各 50 × 50 网格 | 1,027,627 / 1,250,000 | 82.21% |

后两项使用不同的平面和网格分辨率。完整记录中每个测试平面都有对应的样本索引、预测一致的网格点数和总点数。
