## 采集与筛选

- 共记录280个候选资源，保留156张，剔除51个近重复候选、11个低分辨率或占位图、28个视觉核对不通过的候选；34个链接未成功取得图片。
- 牛来按用户提供的黄色牛参考图核对，不把电影中的其他黑牛、红牛、豹等角色混入。网络合集存在角色混杂，已将身份不确定的部分其他造型排除。
- 图片来自已经发布的公开网络资源，没有使用生成模型制作训练样本。**部分已发布素材本身是二创、重绘或渲染版本，不能据此认定其均为动画原帧，亦未核验其是否由AI制作。**
- GIF/动态WebP只保留中间一帧，帧编号记录于清单；透明图片在白底上合成。保留完整画面、文字及原有可见水印，没有另做旋转、翻转、裁切或增广来扩充张数。
- 图像解码后以感知哈希与像素差联合筛除近重复，优先保留分辨率较高者。自动规则并不保证所有同底图换字、同一场景的不同帧都被识别。
- 输出为RGB JPEG，最长边不超过1600像素，不上采样。原始下载文件保存在 `data_collection/raw/`，不进入分类器的类别目录。

## 来源与可复现记录

`data_collection/manifest.csv` 对156张新增图片逐张记录：图片路径、类别、来源页面、直接图片链接、原文件SHA-256、输出SHA-256、原格式、动画帧数、选取帧编号、尺寸和相似分组。完整候选与排除原因分别见 `sources.json`、`audit.json`、`review_exclusions.json`；数量见 `summary.json`。

在 `intro-classification` 目录执行：

```bash
node data_collection/download.mjs

```

下载脚本需要Node.js 18及以上；处理脚本依赖见 `data_collection/requirements.txt`。已有原始文件会复用。网页撤图、防盗链或网络变化可能导致日后无法重新下载，因此保留了此次取得的原始字节。处理脚本仅管理自身导出的图片，不修改奶龙、奶蛙目录。

## 对后续双下降实验的限制

1. 数据量不均衡；单一总体准确率容易被奶龙类别主导，应同时报告分类型结果、宏平均指标及各类训练样本数。
2. 不应把随机图片切分直接当作独立测试。同底图换字、同一动画场景和同一GIF的派生版本可能跨集合泄漏。`similarity_group` 是较宽松的自动提示，需要结合 `page_url`、画面和原视频来源进一步核对；它没有覆盖已有450张图片，不能当作完整的场景标签。
3. 牛来有较多白底二创图，噜噜多为室内动画场景。背景、字幕、画风和网站水印可能成为分类捷径，四类可分不等于模型学到了角色身份。
4. 单条测试误差双下降曲线不能单独验证论文的决策边界机制。后续还需要随模型容量变化测量边界或margin，并区分训练拟合、标签噪声和随机种子的影响。本次数据采集没有产生支持或反驳该机制的实验结果。
